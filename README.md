## 📌 Overview

This project performs **exploratory data analysis (EDA)** on an anime dataset to uncover key insights such as:

* 🏆 Highest scoring anime
* ⭐ Top 5 highest-rated anime
* 📺 Anime with maximum episodes
* ⏳ Longest running anime
* 🛠️ Feature engineering (episode count & timestamps)

---

## 📊 Dataset

* 📁 File: `anime.csv`
* 📌 Contains:

  * Name
  * Score
  * Episodes
  * Airing details
  * Type

---

## ⚙️ Key Features

✔ Data Cleaning & Preprocessing
✔ Feature Extraction (Episodes, Time)
✔ Ranking & Sorting Analysis
✔ Handling Missing Values
✔ Insight Generation
